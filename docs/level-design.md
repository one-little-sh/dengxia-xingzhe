# 《灯下行者》地图设计原则

> 关卡修正与新建关卡的统一依据。协作流程：玩家逐章报问题 → 按本文档逐章修正 → 全部完成后做一次全量审计（硬性规则脚本查 + 体感原则逐关人工核对）。
> 硬性规则已由 `npm run verify` 强制；二、三类是体感原则，审计时人工核对。

## 一、硬性规则（verify 强制，违反即不合规）

1. **行宽一致**：每关所有行字符数相同；外圈必须是完整墙。
2. **恰一个 F 一个 E**：F 是篝火起点（油量回满处），E 是出口。
3. **连通性**：E、所有 T/K/D/$ 从 F 出发可达（断崖 V 按单向规则计入）。
4. **可通关性**：F→E 最小耗油 ≤ 灯油 + 残烛总回油（Dijkstra：碎地 X 计入 dangerCost）。
5. **钥锁配平**：钥匙数 ≥ 锁门数；锁门后的区域必须可达才有意义。
6. **灯币可达**：每枚 `$` 必须可达（放在死角也不许封死）。

## 二、数值哲学（关卡灵魂）

7. **硬走极限**：直奔出口不拾取的最短路线必须剩 0~2 油（紧张状态）；规划路线（篝火/门/残烛）才有从容与全收集——否则障碍与奖励全部被架空。
8. **每关一个教学点**：一关只教一件事；教学关（每章第 1 关）带 `tutorial: true`。
9. **残烛是移动的油**：treasureOil=3 的关里，烛的位置决定路线价值；烛总回油计入预算但**不允许烛成为唯一活路时无提示**（L7 型例外要谨慎）。
10. **门必须有唯一性价值**：捷径门 D 所在的路线，其省油量应大于直走方案，否则门是摆设（L5 教训）。

## 二、数值哲学（补充）

- 诅咒烛 +6 油 / 视野 -1：放入总预算时按「收益是普通烛两倍、代价一档视野」评估。
- 双灯芯关：白芯只能「点状使用」——关卡富余油量决定白芯可用步数（每步多付 1 油）。

## 三、摆放原则（体感与节奏）

11. **灯币放岔路**：`$` 放在偏离最短路的死角、碎地后、断崖下——「走岔路的工钱」，不放主路上。
12. **篝火居中或居边缘要配合门**：篝火回满油的循环半径决定关卡节奏；篝火离出口太近 = 无限续航（禁止）。
13. **碎地成组不成串**：X 单格是「小税」，2~3 格是「抉择」；4+ 格连续必须有绕路选项。
14. **断崖单向可预期**：V 的正下方必须可见或有脉冲可探；不允许「跳下去才发现是死井」（除非该关主题就是深潜）。
15. **幽火出生点离 F 至少 3 格**：开局即追没有博弈空间。
16. **诅咒烛放在主路侧而非必经点**：C 是选择题不是必答题（L32「你需要它」型例外要给足暗示）。
17. **图腾半径覆盖主路才有意义**：R 的 5×5 范围应罩住回头路或收集物，不放在无人区。

## 四、体量与节奏

18. **单关 2~4 分钟**：网格 ≤ 15×9、最短路 ≤ 20 步；章末考核关可放宽到 15×9 上限。
19. **章内递进**：同章 5 关的教学复杂度递增，第 5 关（章末）综合本章机制，异关（第 6 位）打破一条核心假设。
20. **视野半径 ≥ 2 的关**，墙的凹槽深度 ≤ 2（视野 2 时 3 格深的凹槽是永久盲区，慎用）。

## 五、异关专属

21. 异关 id（51+）与数组序号不对应——显示/选关用数组索引。
22. 异关必须配 `tint` 氛围色 + 开场 intro 说明特殊规则。

## 字符速查

`#`墙 `.`地板 `F`篝火起点 `E`出口 `T`宝物/残烛 `D`捷径门 `X`碎地 `K`钥匙 `L`锁门 `V`断崖(只能向南跳) `G`幽火出生点 `C`诅咒残烛 `R`遗忘图腾 `B`抉择门 `$`灯币
